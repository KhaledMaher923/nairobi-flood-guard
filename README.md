Design a modern, professional, high-fidelity UI/UX web application for a project called **“Nairobi Flood Guard AI”**.

### Project Overview

Nairobi Flood Guard AI is an AI-powered flood risk assessment and safe-route guidance platform designed to help citizens, Matatu operators, emergency responders, and authorities understand flood risks across Nairobi and find safer transportation routes.

The platform uses AI/ML to assess flood susceptibility based on environmental and geographical factors and combines this information with route optimization to recommend safer routes.

The design should feel like a **real-world emergency management and intelligent transportation platform**, not a generic analytics dashboard.

### Main Design Goals

* Professional and trustworthy

* Modern AI/technology feeling

* Emergency-response oriented

* Extremely clear and easy to understand

* Map-centric experience

* Strong visual hierarchy

* Responsive on desktop, tablet, and mobile

* Suitable for a hackathon presentation and real-world deployment

### Visual Style

Use a premium modern SaaS/dashboard aesthetic.

Color palette:

* Deep navy / dark blue for the main navigation

* White and light gray for dashboard surfaces

* Teal/cyan for technology and environmental elements

* Green for Low Risk / Safe

* Yellow for Moderate Risk

* Orange for High Risk

* Red for Critical Risk / Emergency

* Use colors carefully and consistently

Use:

* Modern sans-serif typography

* Rounded cards

* Subtle shadows

* Clean spacing

* Minimal borders

* Professional icons

* Smooth micro-interactions

* Clear data visualization

* Glassmorphism only where appropriate and subtle

Avoid excessive gradients, excessive animations, clutter, or overly futuristic cyberpunk styling.

# Important Design Principle

The application should communicate:

**“Predict → Understand → Decide → Act.”**

AI predicts the flood risk.

The interface explains the risk.

The system recommends the safest decision.

The user takes action.

Make the final design look like a **production-ready AI emergency response platform for Nairobi**, with excellent UI/UX, strong information hierarchy, realistic maps, meaningful data visualization, accessible colors, and polished interactions.

Do not create a generic admin dashboard.

Prioritize the **interactive Nairobi map, flood-risk visualization, safe-route optimization, emergency mode, and rainfall simulation** as the core experiences.
